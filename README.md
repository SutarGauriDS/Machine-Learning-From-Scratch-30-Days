# 🚀 30 Days of Machine Learning Challenge

Welcome to my **30 Days of Machine Learning Challenge!** 🎯

This repository documents my **30-day journey** of learning Machine Learning from scratch while building projects, solving coding problems, and sharing my progress publicly.

The goal is to become **interview-ready for Machine Learning Engineer and Data Scientist roles** by mastering the fundamentals, implementing algorithms, and creating a strong GitHub portfolio.

# ▶️ Getting Started

Clone the repository

```bash
git clone https://github.com/SutarGauriDS/30-Days-of-Machine-Learning.git
```

Move into the project

```bash
cd 30-Days-of-Machine-Learning
```

Install dependencies

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook

```bash
jupyter notebook
```
