# 🚀 Day 5 – Pandas Pivot Table & Data Visualization

## 30 Days of Machine Learning Challenge

Today I learned how to **summarize data using Pandas Pivot Tables** and turn those summaries into useful visual insights using **Matplotlib and Seaborn**.

## 🎯 Topics Covered

* **Pivot Tables** — Summarized sales data using `pivot_table()`.
* **GroupBy** — Aggregated sales by product and region.
* **Bar Chart** — Compared total sales across products.
* **Line Chart** — Analyzed monthly sales trends.
* **Scatter Plot** — Explored the relationship between quantity and sales.
* **Histogram** — Studied the distribution of sales.
* **Heatmap** — Compared product sales across different regions.
* **Business Insights** — Used the analysis to identify top-performing products and regions.

## 📊 Visualizations

The notebook contains a **2×2 visualization layout** with:

```text
┌─────────────────┬─────────────────┐
│   Bar Chart     │   Line Chart    │
│  Sales/Product  │ Monthly Sales   │
├─────────────────┼─────────────────┤
│ Scatter Plot    │   Histogram     │
│ Quantity/Sales  │ Sales Distribution │
└─────────────────┴─────────────────┘
```

A separate **Heatmap** is also used for Product × Region sales analysis.
