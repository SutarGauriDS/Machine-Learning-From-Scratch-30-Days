# 🚀 Day 6 – Machine Learning Workflow & Train-Test Split

## 30 Days of Machine Learning Challenge

Today I learned the basic **Machine Learning workflow** and how to divide data into training and testing sets.

### 📚 Topics Covered

* **ML Workflow** — Understanding the steps from data collection to model evaluation.
* **Features & Target** — Separating input variables (`X`) from the output (`y`).
* **Train-Test Split** — Dividing data into training and testing sets.
* **`test_size`** — Controlling the percentage of data used for testing.
* **`random_state`** — Making data splitting reproducible.
* **Data Leakage** — Understanding how incorrect preprocessing can lead to misleading model performance.
* **Overfitting** — Understanding why a model should perform well on unseen data.
