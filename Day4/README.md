# 🚀 Day 4 – Pandas for Machine Learning

## 30 Days of Machine Learning Challenge

Today I learned **Pandas**, a powerful Python library for data manipulation, cleaning, and analysis.

### 📚 Topics Covered

* **Series & DataFrame** — Working with Pandas data structures.
* **Data Exploration** — Using `head()`, `tail()`, `shape`, `info()`, and `describe()`.
* **Selecting Data** — Selecting rows and columns using `loc` and `iloc`.
* **Filtering** — Finding records based on conditions.
* **Sorting** — Organizing data using `sort_values()`.
* **Missing Values** — Detecting and filling missing data.
* **GroupBy** — Grouping data and calculating statistics.
* **Statistics** — Finding mean, maximum, and minimum values.
* **New Columns** — Creating new features from existing data.
