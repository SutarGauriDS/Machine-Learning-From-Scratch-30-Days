## 🧠 What is K-Means?

K-Means is an **unsupervised clustering algorithm** that groups similar observations into `K` clusters.

The algorithm works by:

1. Choosing the number of clusters `K`
2. Initializing cluster centroids
3. Assigning each data point to its nearest centroid
4. Recalculating the centroid of each cluster
5. Repeating the process until the clusters stabilize

### Simple Workflow

```text
Data
 ↓
Choose K
 ↓
Initialize Centroids
 ↓
Assign Points
 ↓
Update Centroids
 ↓
Repeat
 ↓
Final Clusters
```

## 📉 Elbow Method

The **Elbow Method** is used to investigate a suitable number of clusters.

For each value of `K`, the model's **inertia** is calculated.

### Inertia / WCSS

Inertia represents the sum of squared distances between each observation and its nearest cluster centroid.

A lower inertia generally means more compact clusters.

However, increasing `K` will generally reduce inertia, so we look for an **elbow point** where additional clusters provide diminishing improvement.

```text
K = 1
K = 2
K = 3
...
K = 10
```

The project uses **K = 5** for the main experiment based on the typical elbow pattern of this dataset.

---

## 🎯 K-Means Implementation

```python
kmeans = KMeans(
    n_clusters=5,
    random_state=42,
    n_init=10
)

cluster_labels = kmeans.fit_predict(X_scaled)
```

The resulting cluster labels are added to the original dataset.

It is used here to demonstrate how clustered data can be represented in a principal-component space.
