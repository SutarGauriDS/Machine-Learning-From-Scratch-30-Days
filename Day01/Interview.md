# 🎯 Day 1 Interview Questions

## Q1. What is Machine Learning?

**Answer:**
Machine Learning is a subset of Artificial Intelligence that enables computers to learn patterns from data and make predictions without being explicitly programmed.

---

## Q2. Why is Machine Learning important?

**Answer:**
Machine Learning helps solve problems where writing explicit rules is difficult or impossible, such as spam detection, fraud detection, recommendation systems, and image recognition.

---

## Q3. What is the difference between Artificial Intelligence and Machine Learning?

| Artificial Intelligence | Machine Learning |
|-------------------------|------------------|
| Broad field of creating intelligent systems | Subset of AI |
| Can work using predefined rules | Learns from data |
| Focuses on intelligent behavior | Focuses on learning patterns |

---

## Q4. What is a Machine Learning Model?

**Answer:**
A Machine Learning model is a mathematical representation learned from historical data that is used to make predictions on new, unseen data.

---

## Q5. What are some real-world applications of Machine Learning?

- Netflix Recommendation System
- Gmail Spam Detection
- Credit Card Fraud Detection
- Face Recognition
- Customer Churn Prediction
- Medical Diagnosis

---

## Q6. Explain the basic Machine Learning workflow.

Problem Definition → Data Collection → Data Preprocessing → Model Training → Model Evaluation → Prediction → Deployment

---

## Q7. What is the difference between Training and Prediction?

**Training:** Learning patterns from historical data.

**Prediction:** Using the trained model to make predictions on new data.

---

## Q8. What are Features and Target Variables?

**Features (X):** Input variables used for prediction.

**Target (y):** Output variable that the model predicts.
