# 🎯 Day 3 – NumPy Interview Questions

## 1. What is NumPy?

NumPy is a Python library used for numerical computing and working with arrays.

## 2. Why is NumPy used in Machine Learning?

It provides efficient operations for numerical data, arrays, matrices, and mathematical calculations.

## 3. What is a NumPy array?

A NumPy array is a data structure used to store numerical values efficiently.

## 4. What is `ndim`?

`ndim` returns the number of dimensions of an array.

```python
arr.ndim
```

## 5. What is `shape`?

`shape` tells us the size of an array along each dimension.

```python
arr.shape
```

## 6. What is `size`?

`size` returns the total number of elements in an array.

```python
arr.size
```

## 7. What is `dtype`?

`dtype` tells us the data type of the elements in an array.

## 8. What is the difference between a Python list and NumPy array?

NumPy arrays are designed for efficient numerical operations and generally provide faster vectorized calculations than standard Python lists.

## 9. What is vectorization?

Vectorization means performing operations on an entire array without explicitly writing a Python loop for every element.

## 10. What does `reshape()` do?

It changes the shape of an array without changing the values.

```python
arr.reshape(2, 3)
```

## ⭐ Important Questions

For interviews, focus especially on:

* What is NumPy?
* Why is NumPy important for ML?
* NumPy array vs Python list
* `shape` vs `size` vs `ndim`
* What is vectorization?
* What is `reshape()`?
