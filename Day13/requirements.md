
## 📦 Requirements

| Package        | Purpose                                                             |
| -------------- | ------------------------------------------------------------------- |
| `pandas`       | Data loading, DataFrame creation, and analysis                      |
| `matplotlib`   | Accuracy and class-distribution visualizations                      |
| `scikit-learn` | Dataset, preprocessing, SVM model, train-test split, and evaluation |
| `jupyter`      | Running the `.ipynb` notebook                                       |

### Installation

Create and activate your virtual environment if you are using one:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

You can verify the installation with:

```bash
python -c "import pandas, matplotlib, sklearn; print('All packages installed successfully!')"
```
