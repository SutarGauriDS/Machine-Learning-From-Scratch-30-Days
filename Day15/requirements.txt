Then install everything:

Or install directly:


pip install pandas matplotlib scikit-learn jupyter


### What each package is used for:

| Package        | Purpose                                                              |
| -------------- | -------------------------------------------------------------------- |
| `pandas`       | Loading and manipulating the Titanic dataset                         |
| `matplotlib`   | Creating visualizations                                              |
| `scikit-learn` | Preprocessing, Logistic Regression, train-test split, and evaluation |
| `jupyter`      | Running the `.ipynb` notebook                                        |
