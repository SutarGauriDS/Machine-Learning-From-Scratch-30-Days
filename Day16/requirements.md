## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

---
## 📦 Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

Or install them directly:

```bash
pip install pandas matplotlib scikit-learn jupyter
```

---

## ▶️ Run Python File

```bash
python day16_feature_selection.py
```

---

## 📓 Run Jupyter Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
Day16_Feature_Selection_Complete.ipynb
```

Run the cells sequentially.
